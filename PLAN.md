# DocuMind AI · план разработки

- [x] Инвентаризация, приоритеты ТЗ, сверка схемы.
- [x] Каркас API и SPA, миграции, Docker Compose, сессии.
- [x] Библиотека, приватное хранилище, очередь, парсинг и векторный индекс.
- [x] Потоковый RAG-чат с источниками, обзор, оформление и адаптивность.
- [x] P1: анализ, сравнение, экспорт и отдельный демонстрационный режим.
- [x] Локальные проверки Compose, Alembic, Pytest, Vitest и Playwright.
- [x] Проверка реального Ollama, PDF-просмотра и демо-команды.
- [x] Редизайн «Оптический считыватель», навигация по цитатам и мобильная проверка.
- [x] Финальные скриншоты и GIF для портфолио.
- [x] OCR для сканов PDF, повторная приёмка и подготовка GitHub-репозитория.

Nginx объединяет API и SPA в одном origin. FastAPI проверяет сессию и право
владения ресурсом. PostgreSQL хранит метаданные и векторы, MinIO — оригиналы,
Celery через Redis обрабатывает документы. LLM получает только отобранные
фрагменты. Локальный запуск остаётся в рабочей папке.

Код GitHub Actions подготовлен. Для локальной проверки использованы команды
workflow на отдельном Compose-стеке. Внешний совместимый AI API требует
URL и ключа владельца установки. Гибридное ранжирование остаётся в roadmap.
