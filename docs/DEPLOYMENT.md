
# Run and deploy

Use Docker Engine or Docker Desktop with Compose v2.24.4 or later and
allocate enough memory for the optional Ollama model. Only Nginx binds a
host port, on loopback. The first build downloads Compose images, compiles
MinIO Community Edition from a pinned source release, and installs CPU
PyTorch. The local model cache is shared by the API and the worker.

## Local

PowerShell on Windows

```powershell
./scripts/init-env.ps1
docker compose up --build -d --wait
```

Linux

```sh
sh scripts/init-env.sh
docker compose up --build -d --wait
```

Open `http://localhost:8080`. Change both `APP_PORT` and `APP_ORIGIN` to use
a different port. If the environment already exists, reuse it. Start Ollama
as described in [AI providers](AI_PROVIDERS.md).

| Settings | Purpose |
| --- | --- |
| `JWT_SECRET`, `DATABASE_PASSWORD`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY` | Required. Generated by the environment setup scripts. |
| `APP_ORIGIN`, `APP_PORT`, `ENVIRONMENT` | Public browser origin, local port and environment. |
| `DATABASE_NAME`, `DATABASE_USER`, `MINIO_BUCKET` | Logical database and private bucket names. |
| `AI_PROVIDER`, `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY`, `AI_EXTERNAL` | Server-side provider configuration. |
| `MAX_DOCUMENTS`, `MAX_FILE_MB`, `MAX_STORAGE_MB`, `MAX_JOBS`, `MAX_AI_DAILY` | Upload, storage, queue and usage limits. |
| `OCR_ENABLED`, `OCR_LANGUAGES`, `OCR_MAX_PAGES`, `OCR_PAGE_TIMEOUT`, `OCR_DOCUMENT_TIMEOUT` | Local scanned-PDF OCR. Defaults are enabled, Russian and English, 30 pages, 15 seconds per page and 120 seconds per document. |
| `EMBEDDING_MODEL`, `EMBEDDING_DEVICE`, `CHUNK_SIZE`, `CHUNK_OVERLAP`, `TOP_K`, `RELEVANCE_THRESHOLD` | Retrieval configuration. |

The image includes Russian and English Tesseract models for local execution.
OCR preserves the original PDF and stores recognized text separately.
On existing installations, migrations run on startup. Use **Повторить
обработку** on an earlier failed scan to index it with OCR.

## Private VPS deployment

Use a TLS reverse proxy on the same host, forward to the loopback Nginx
listener, and set `ENVIRONMENT=production` and the exact HTTPS
`APP_ORIGIN`. Preserve the Host header and streaming delivery. The refresh
cookie will use Secure. Allow ingress to the edge proxy only. Keep
PostgreSQL, Redis, MinIO and the Ollama API private. Keep environment files
outside Git and restrict their permissions.

Back up PostgreSQL and MinIO together. Test restoration including migrations
and the consistency of document and object keys. Configure trusted execution
environments and same-origin TLS before inviting other users. The sample
installation uses one MinIO identity and a PostgreSQL bootstrap role, so
separate runtime and migration privileges when hardening a shared instance.
MinIO's source and runtime retain their upstream license.
