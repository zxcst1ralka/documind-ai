
# Changelog

## 1.1.0

- Added local Russian and English OCR for scanned PDF pages, including
  page citations and a recognized-page count in document details.
- Added regression tests for mixed PDFs and an end-to-end OCR workflow.

## 1.0.0

- Private document workspace with Russian interface and dual themes.
- Rotating account sessions, upload processing, vector search and streaming
  AI answers with source previews.
- Document and contract analysis, deterministic comparison, PDF/DOCX/Markdown
  exports and a read-only demonstration account.
- Docker Compose, isolated backend/UI testing, provider smoke test, API and
  architecture documentation.
